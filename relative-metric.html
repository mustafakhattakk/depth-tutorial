Relative depth and metric depth

Listen to this page

What relative depth means

A relative depth map gets the order right but not the units. It can tell you that the chair is closer than the door, and roughly how the scene is laid out, but its values have an unknown scale. Many popular models go one step further and predict inverse depth (often called disparity, because large values mean close) that is only correct up to an unknown scale s and shift t for each image. In other words, the true inverse depth equals s times the prediction plus t, and the model does not know s or t.

MiDaS was trained this way on purpose [3]. Its training data mixed laser scans, stereo pairs and frames from 3D movies, each with a different and often unknown scale. By only asking the network to be right up to scale and shift, all these sources could be used together.

What metric depth means

A metric depth map gives values in real units, normally meters. The difference is easy to state with an example:

  • Relative: "Chair A is closer than chair B, and B is roughly twice as far."
  • Metric: "Chair A is 1.5 meters away and chair B is 3.1 meters away."

Only the second sentence lets the system decide whether to warn the user now or wait.

Scale ambiguity in monocular vision

Figure 3 shows the core problem. A small box one meter away and a box three times larger three meters away fill the same rays and produce the same image. A network resolves this by guessing from experience: doors are about two meters tall, so a door filling half the frame is probably a few meters away. That guess breaks for objects without a typical size, such as walls, poles or unusual furniture.

The camera itself adds a second ambiguity. A phone with a wide lens and a phone with a zoom lens see the same object at the same distance at different sizes. A model trained on one camera can therefore be systematically wrong on another. Metric3D addresses this by converting all training images into a single canonical camera before learning [4].

Why metric depth is harder

  • Less training data. Metric labels need calibrated sensors. The standard benchmarks are NYU Depth V2 for indoor rooms, captured with a Kinect [5], and KITTI for driving, captured with a laser scanner on a car [6]. Neither looks like a pedestrian holding a phone.
  • Dependence on the camera. Focal length and sensor size change the answer, as explained above.
  • Errors grow with distance. Because many models work in inverse depth, a small error in disparity at the far end of a room becomes a large error in meters.

When relative depth is still useful

Relative depth is not useless for navigation. It can rank obstacles from nearest to farthest, find the closest object in each part of the image, and reveal sudden jumps in the floor that suggest a step or drop off. If the scale stays roughly constant between frames, the rate at which an obstacle's depth shrinks can even estimate time to contact without knowing meters. The catch is that per image scale can drift between frames, so these tricks need care.
