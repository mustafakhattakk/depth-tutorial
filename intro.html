Introduction and problem definition

Listen to this page

What monocular depth estimation is

A phone camera records a flat grid of colors. Monocular depth estimation is the task of predicting, for every pixel in that grid, how far the visible surface is from the camera, using only that one image or a stream of single images. The result is a depth map: an image the same size as the input in which each value is a distance instead of a color.

Eigen, Puhrsch and Fergus showed in 2014 that a convolutional network could learn this mapping directly from pairs of photos and depth sensor scans [1]. Almost every modern system still follows that basic recipe: show a network millions of images with known depth and let it learn which visual patterns mean near and which mean far.

Why a single camera cannot directly measure depth

When a camera projects the 3D world onto its sensor, the distance along each viewing ray is thrown away. In the pinhole camera model a point at (X, Y, Z) lands on pixel (u, v):

u = f · X / Z + cx v = f · Y / Z + cy (X, Y, Z) and (2X, 2Y, 2Z) land on the same pixel (u, v)

Scaling the whole scene by any factor gives exactly the same picture. So infinitely many 3D scenes can produce the same photo, and depth cannot be recovered by geometry alone. People and networks get around this with learned cues: the usual size of familiar objects, hallway lines that meet at a vanishing point, texture that gets finer with distance, objects hiding each other, shading, and where things touch the floor. These cues are statistics about the world, not measurements, and statistics can be wrong.

Detecting an object versus knowing how far away it is

An object detector can say "there is a chair in the lower middle of the image." That is useful, but it does not tell a walking person whether the chair is two steps away or ten. Detection answers what and where in the image. Depth answers where in the world. An assistive system needs both, and depth is the part that turns a label into an action such as "stop" or "veer left."

Why depth accuracy matters for assistive navigation

Blind and low vision travelers already rely on white canes and guide dogs, which are excellent at close range. Camera based aids add the most value for what the cane misses: obstacles at chest or head height, objects several meters ahead, and drop offs such as stairs going down. Surveys of wearable assistive devices [2] cover many camera, ultrasonic and depth sensor prototypes. The lesson I take from that body of work is simple: a device is only useful if the person wearing it can trust what it says.

Why a wrong distance can be worse than a missed object

If the system misses an obstacle, the user is no worse off than without the device, because the cane is still there. If the system confidently says "path clear for three meters" when a glass door is one meter away, it is actively telling the user to walk forward with confidence. Constant false alarms are harmful in a different way: users learn to ignore the device.

The goal of this tutorial

A useful assistive depth system must do three things: report distances in real units, attach a confidence to each distance, and say "I don't know" when the scene is one it handles badly. The rest of the tutorial builds these three abilities step by step.
